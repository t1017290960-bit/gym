PocketBase 後台需建立的資料表與規則

先建立 Auth collection users（使用一般帳戶登入，切勿把 superuser 帳戶或金鑰放在網頁）。再建立以下 Base collections，欄位名稱與型別需一致：

workout_records：user（Relation → users，必填）、clientId（Text）、date（Text）、name（Text）、met（Number）、duration（Number）、calories（Number）。

food_records：user（Relation → users，必填）、clientId（Text）、date（Text）、name（Text）、meal（Text）、calories（Number）。

sleep_records：user（Relation → users，必填）、clientId（Text）、date（Text）、hours（Number）、quality（Text）、sleepCalories（Number，睡眠消耗估算）。

fitness_profiles：user（Relation → users，必填）、weight（Number）、height（Number）、age（Number）、gender（Text）、activity（Number）、goal（Number）、updatedAt（Date）。

四個資料表的 List/View/Update/Delete 規則設為 @request.auth.id != "" && user = @request.auth.id；Create 規則設為 @request.auth.id != "" && @request.body.user = @request.auth.id。建立後，用一般使用者帳戶登入。Tunnel 網址可能變動，若網址失效請更新上方網址。熱量與運動資料屬個人資料，請勿設為公開讀取。

熱量與體脂相關數字均為粗略估算。請以長期趨勢、專業建議及自身狀況為準。
